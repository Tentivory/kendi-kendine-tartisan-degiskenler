# Kendi Kendine Tartışan Değişkenler

Bu repository, modern yazılım mühendisliğinin zirvesini temsil eder. İki basit değişken, hiçbir amaç gütmeden sürekli birbirleriyle tartışır.

## Neden Bu Proje?

Çünkü değişkenler de insan gibi duygulara sahip olabilir. Belki de değildir. Ama tartışırlar.

## Nasıl Çalışır?

Python scriptini çalıştırın. Sonsuza kadar (veya Ctrl+C ile) değişkenler birbirine laf sokar.

```bash
python tartisma.py
```

## Özellikler

- Tamamen anlamsız tartışmalar
- Hiçbir şey çözmez
- CPU'yu boş yere meşgul eder (eğlence için)
- Ciddi görünür ama değildir

## Katkıda Bulunma

Lütfen katkıda bulunmayın. Değişkenler zaten yeterince kızgın.
